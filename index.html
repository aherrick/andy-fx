One script tag. AndyFX reads the visitor's date and browser locale, picks the right holiday, and quietly animates. Fully client-side — no APIs, no tracking, no setup.

    API
    
      
    That's everything. Methods return the instance, so they chain.
    
      
    
        
    
          
    Options
    
          
    
            
    theme = 'auto'
    'auto', 'off', or any name in AndyFX.themes
    
            
    country = 'auto'
    ISO code like 'US', or 'auto' to read the browser locale
    
            
    intensity = 'normal'
    'subtle', 'normal', or 'party'
    
            
    fallback = 'none'
    'seasonal' shows the season when there's no holiday
    
          
    
          
    Static
    
          
    
            
    AndyFX.themes
    Array of every theme name
    
            
    AndyFX.detectTheme(date?, { country, fallback })
    Theme 'auto' would pick for a date
    
            
    AndyFX.detectCountry()
    Region from the browser locale, or null
    
            
    AndyFX.upcoming({ country, limit })
    Holidays in the next year as { name, theme, countries, start, end, now }, including one underway today. Pass country: 'all' to ignore regions; countries is null for holidays not limited to specific countries
    
          
    
        
    
        
    
          
    Instance
    
          
    
            
    new AndyFX(options?)
    Create an instance; nothing renders until start()
    
            
    .start()
    Begin effects; pauses automatically while the user prefers reduced motion or has opted out
    
            
    .stop()
    Pause and clear the screen
    
            
    .destroy()
    Stop and remove the overlay from the page
    
            
    .setTheme(name)
    Same values as the theme option
    
            
    .setCountry(code)
    Same values as the country option
    
            
    .setIntensity(level)
    Same values as the intensity option
    
            
    .setFallback(mode)
    Same values as the fallback option
    
            
    .optOut() · .optIn()
    Remember the visitor's choice on this site (localStorage); wire to your own button
    
            
    .theme · .country · .running · .paused · .optedOut
    Read-only: current theme, resolved country, whether it's started, whether reduced motion or opt-out is holding it back, and whether the visitor opted out
    
          
    
        
    
      
    

      
    
        
    
          
    🔒
    
          
    Private by design
    
          
    No IP lookups or network calls. Country comes from the browser locale.
    
        
    
        
    
          
    🪶
    
          
    Featherweight
    
          
    One file, zero dependencies, CSS animations isolated in a shadow DOM.
    
        
    
        
    
          
    ♿
    
          
    Polite
    
          
    Respects reduced motion, lets visitors opt out, never blocks clicks, pauses in background tabs.
