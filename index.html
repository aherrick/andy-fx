    API
    
      
    That's everything. Methods return the instance, so they chain.
    
      
    
        
    
          
    Options
    
          
    
            
    theme = 'auto'
    'auto', 'off', or any name in AndyFX.themes
    
            
    country = 'auto'
    ISO code like 'US', or 'auto' to read the browser locale
    
            
    intensity = 'normal'
    'subtle', 'normal', or 'party'
    
            
    fallback = 'none'
    'seasonal' shows the season when there's no holiday
    
          
    
          
    Static
    
          
    
            
    AndyFX.themes
    Array of every theme name
    
            
    AndyFX.detectTheme(date?, { country, fallback })
    Theme 'auto' would pick for a date
    
            
    AndyFX.detectCountry()
    Region from the browser locale, or null
    
          
    
        
    
        
    
          
    Instance
    
          
    
            
    new AndyFX(options?)
    Create an instance; nothing renders until start()
    
            
    .start()
    Begin effects (skipped if the user prefers reduced motion)
    
            
    .stop()
    Pause and clear the screen
    
            
    .destroy()
    Stop and remove the overlay from the page
    
            
    .setTheme(name)
    Same values as the theme option
    
            
    .setCountry(code)
    Same values as the country option
    
            
    .setIntensity(level)
    Same values as the intensity option
    
            
    .setFallback(mode)
    Same values as the fallback option
    
            
    .theme · .country · .running
    Read-only: current theme, resolved country, and whether it's playing
    
          
    
        
    
      
    

      
    
        
    
          
    🔒
    
          
    Private by design
    
          
    No IP lookups or network calls. Country comes from the browser locale.
    
        
    
        
    
          
    🪶
    
          
    Featherweight
    
          
    One file, zero dependencies, CSS animations isolated in a shadow DOM.
    
        
    
        
    
          
    ♿
    
          
    Polite
    
          
    Respects reduced motion, never blocks clicks, pauses in background tabs.
